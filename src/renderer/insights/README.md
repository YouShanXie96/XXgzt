# 数据功能界面

这些文件仅负责展示、筛选和用户操作，不采集后台、不计算推荐，也不直接读取本地文件。

| 文件 | 职责 |
| --- | --- |
| `core.js` | 页面注册、按店铺隔离的界面状态、IPC 操作、导入预览与确认 |
| `business.js` | 生意参谋指标和保存记录 |
| `trends.js` | 关键词批次选择、曲线、日明细、分析包导出入口 |
| `peers.js` | 达摩盘榜单快照和区间指标展示 |
| `recommendations.js` | 已导入推荐的月份、关键词、类目筛选 |
| `insights.css` | 以上页面和导入预览的响应式样式 |

脚本加载顺序：`core.js` → 各页面 → 主程序 `app.js`。页面通过 `XXInsights.register` 注册；主程序通过 `XXInsights.create(host)` 创建实例并转发渲染、点击和字段变化。

数据与接口定义在 `src/insights`。界面消费规范字段，不改变来源数据口径。缺失指标显示“—”，曲线保留断点；动态内容一律转义。导入对话框展示已校验文件，确认时使用服务端生成且绑定店铺的临时凭据，不在界面内替用户改写数据。

单独验证界面逻辑：`tools/node.exe --test tests/insights-ui.test.js`。
