# 谢谢工作台 v0.12.8 更新记录

## 组织与注册

- 修复部门和小组右侧菜单按钮点击后菜单立即消失的问题；现在可继续选择新建子部门、重命名、移动、删除等操作。
- 注册页查询公司后读取登录管理中心返回的真实部门和小组，并根据所选部门联动显示小组。
- 注册申请会把员工选择的部门和小组提交给登录管理中心，审核弹窗继续支持修改。
- “账号与权限 → 成员”新增“复制公司邀请码”，点击后直接写入系统剪贴板。

## 权限

- 工作台继续只显示普通公司成员；隐藏超级管理员不会出现在成员、组织架构或系统层级中。
- 隐藏超级管理员仍由登录管理中心创建和管理，登录工作台时使用目标公司老板的全部业务权限。
- 查看、编辑部门和小组继续由登录管理中心的管理权限与角色控制。

## 外观

- 切换浅色、深色和护眼模式时不再在左下角弹出成功提示。
- 护眼模式补齐店铺日报、精细化的筛选区、表格、同步面板和编辑弹窗配色。

## 版本

- 主程序版本更新为 v0.12.8。
- 上一版 v0.12.7 程序与源码继续保留。
