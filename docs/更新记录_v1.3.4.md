# 更新记录 v1.3.4（2026-11-12）

## 1. 上架字段填不进去（日志：`表单项=0`、`[fill-attrs] 命中 0/21`）

现场抓发布页 DOM 得到真实结构：

- 字段行 = `div.sell-component-info-wrapper-wrap`
- 标签 = `span.sell-component-info-wrapper-label`
- 控件 = 标签容器的**下一个兄弟** `div.sell-component-info-wrapper-component-wrap`

旧代码按 `.next-form-item` 找，一个都匹配不到；`closest('div')` 又只拿到标签外壳，里面没有输入框。

改成 `fillFormScript`：按「标签 → 标签容器 → 控件容器」找控件，并区分三类：
可写 `input/textarea`、`next-select/cascader`（点开选项再点值）、`radio/checkbox`（点文字）。

在真实发布页（catId=201840605）实测：

```
[fill-form] 命中 12/21（文本 7 · 下拉 5 · 单选/多选 0）
回读：包装方式=散装 / 是否独立包装=独立包装 / 适用场景=早餐 / 特色工艺=手工制作 /
      成分特点=0反式脂肪酸 / 生产许可证编号=SC12432030500378 /
      厂名*=徐州桃源居食品有限公司 / 厂址*=江苏省徐州市… / 储藏方法=见包装 / 食品添加剂=无
未命中：产品净含量、包装种类、配料表、系列、品名、产地、生产日期、包装规格、单件净含量
       （这些标签在该页面上不存在，页面用的是 条形码/成分表/配料）
```

## 2. 就绪判定（日志：`发布页就绪（91s）表单项=0`）

按「可见输入框数量 ≥ 6 且连续两次不变」判断，不再等 `.next-form-item`，不再白等 90 秒。
日志改为：`发布页就绪（Ns）engine=yes 表单项=0 输入框=93 上传框=1`。

## 3. SKU 行（日志：`[fill-sku] 填充 SKU 0/27`）

新版发布页没建规格时 SKU 表里只有「+ 创建规格」，点开是抽屉（单层展示 / 分层展示）。
新增 `createSkuSpecsScript`：点创建 → 选「单层展示·自定义填写规格」→ 填规格名 → 逐个填规格值 → 确认创建。
日志会写：`[fill-sku] 创建规格「商品规格」：成功，SKU 行 N 条` 或 `未成功（原因；步骤 …）`。
（这一步还在真机调，值输入框的定位需要下一次日志确认。）

## 4. 发布页窗口关不掉

天猫发布页挂 `beforeunload`，点 × 被拦。现在窗口 `close` 事件先 `preventDefault` 再 `destroy()`，
× 立刻生效（发布页内容不需要保存）。
