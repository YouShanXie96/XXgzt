# 谢谢工作台 v0.13.2 更新记录

## 功能权限界面

- 删除不必要的权限配置说明文字。
- 压缩“复制下级权限”区域高度。
- 一级分类改为横向分类带，二级和三级权限继续按列显示。
- “店铺管理”权限组改名为“店铺与登录”。

## 审核入口

- 删除账号与权限顶部独立的“待审核”页签。
- 成员页面新增“审核”按钮，待审核申请在弹窗中查看、通过或拒绝。

## 店铺授权层级

- 部门店铺授权只提供给部门主管；小组店铺授权只提供给组长。
- 部门主管可以管理其部门及下级部门内的下级成员，组长可以管理本组组员。
- 普通组员不再因部门或小组店铺授权自动获得店铺；管理者需要把店铺直接授权给具体成员。

## 授权卡片

- 统一按人、按店授权卡片的头像、名称、说明和操作按钮布局。
- 增加、移除个人店铺授权后不再显示右下角提示。

## 版本

- 最新版本更新为 v0.13.2，上一版备份为 v0.13.1。
