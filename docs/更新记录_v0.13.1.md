# 谢谢工作台 v0.13.1 更新记录

## 店铺授权修复

- 修复登录管理中心已有成员尚未写入工作区时，用户店铺授权保存后被丢弃的问题。保存前会补齐该成员的部门、小组和层级归属，再写入店铺授权。
- 组织授权保存、按人授权和按店授权保存后，会立即刷新当前工作台的店铺范围。
- 店铺登录、经营数据、店铺浏览器和店铺缓存继续共用同一份授权范围。

## 按组织授权

- 在人员列选择一个成员后，右侧店铺会自动勾选该成员已经获得的店铺。
- 直接授权可以通过复选框新增或移除；部门或小组继承来的店铺保持勾选并锁定，避免误删继承关系。
- 店铺行不再显示“已授权：全公司（老板默认）”等授权来源文字。

## 按钮与文案

- 授权方式按“按组织授权、按人授权、按店授权”排列。
- “按人查询”“按店查询”统一改为“按人授权”“按店授权”。

## 验证

- 完整自动测试、隔离界面测试、发布包与源码逐文件指纹校验通过后才发布。
- 真实店铺凭据不进入测试夹具、源码包或发布包。
