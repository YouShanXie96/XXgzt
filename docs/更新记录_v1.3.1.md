# 更新记录 v1.3.1（2026-11-11 晚六）· 上架填写稳定性

问题：用户问「我点上架，会自动填进去吗」。上一版能填，但有三处**在真实发布页上容易空跑**，
这一版专门修它们，确保「点了就真的往里填」，填不进去也会在日志里说清楚。

## 1. 发布页就绪判定太硬（最常见的「一上来就失败」）

- 旧：`ready = Boolean(__SELL_STATE__.engine)`。新版发布页换了组件后这个对象可能没有，直接 `PAGE_MISMATCH`，**一个字都不填**。
- 新：`ready = engine || (标题输入框 + 提交按钮都在 DOM 里)`；探针额外返回 `domReady / formItems / fileInputs`，
  日志写 `发布页就绪（Ns）engine=… domReady=… 表单项=N 上传框=N`。

## 2. 图片组件要「先点上传才挂出 input[type=file]」

- 旧：扫一次没找到上传框就直接报「没有图片上传入口」，主图不填。
- 新：扫不到就点一次「上传图片 / 上传主图 / 本地上传」（跳过视频、详情、资质里的按钮）→ 再扫；
  上传后自动点弹窗里的「确定 / 确认 / 保存」，再**回读主图区图片数量**并写日志 `主图区回读 N 张`。

## 3. 规格行匹配太脆（长名字被表格截断就匹配不上）

- 旧：只按「前 10 个字包含」找行。
- 新：先精确包含，再按**字二元组重合度**兜底；候选分差 <0.08（有歧义）就不猜，宁可报未命中也不写错价格。
- 同时扩展了行容器选择器（`.next-table-row`、`[class*="skuItem"]`、`[class*="tableRow"]`，且必须是含 input 的行）。

## 4. 属性名不是完全一致时也能命中

- `xhFindByLabel` 增加**包含兜底**：发布页把 label 写成「产地（省份）」「净含量 / 规格」这类变体时，
  只在**唯一命中**时采用，多个候选一律放弃（不猜）。
