# 谢谢工作台 v0.13.0 更新记录

## 店铺授权范围

- 店铺管理只显示当前管理账号自己已获授权的店铺，不再显示公司内与本人无关的店铺。
- 经营数据可以直接加载登录管理中心已经授权的店铺，不要求先在“店铺登录”里重新添加。
- 未授权店铺即使保存过平台登录状态，也不会出现在店铺列表、经营数据选择器或店铺管理中。
- 授权店铺在本机缺少登记记录时，会按登录管理中心返回的店铺编号和名称恢复本地登记及对应数据文件夹。
- 如果程序目录内只有空的“用户数据”，工作台会安全查找最近两层上级中的真实“用户数据”并继续使用；只读取，不移动、不覆盖原数据。

## 按人 / 按店查询

- 店铺管理新增“按人查询”“按店查询”和原“按组织授权”三种方式。
- 按人查询：左侧选员工，中间显示已授权店铺，右侧显示本人有权限但尚未授权给该员工的店铺。
- 按店查询：左侧选店铺，中间显示已授权人员，右侧显示当前可继续授权的下级人员。
- 左右查询区均支持搜索；部门和小组继承来的授权会标明来源，无法从单个成员上误删。
- 上级可以给直属下级及更下一级授权，服务端继续校验部门、小组和人员层级范围。

## 权限层级

- “设置功能权限”改为一级分类、二级分类、三级功能按钮的清晰层级。
- “账号与权限”一级分类下新增“我的、待审核、成员、系统层级、店铺管理”二级分类。
- 功能按钮改用实际业务名称，例如查看成员、新增成员、复制公司邀请码、新建部门、权限模板、店铺分配等。
- 一级分类固定在权限列表可见区域顶部，长列表滚动时“账号与权限 / 工作台”不会显示为空白。
- 无对应权限的页签和按钮不会显示；登录管理中心和工作台服务端同时复核权限。

## 设置与店铺缓存

- “设置 → 店铺缓存”只显示当前账号有权查看的店铺。
- 新增全选功能。
- 店铺选择项改为横向网格，排满后自动换行。

## 版本

- 主程序版本更新为 v0.13.0。
- 仅保留最新版与上一版 v0.12.9 的程序备份和源码备份。
