# 更新记录 v1.0.7（2026-11-11 晚）

对应插件：**AI作图插件 0.6.13**

## 1. 视频采集到了但看不到内容

- 视频列表新增 `<video controls>` 缩略预览 + 「打开」新窗口播放
- 视频计数改为按 URL 去重（原来「视频 2」但列表只有 1 条）
- 采集侧补：`<video data-src/data-video>`、`og:video`、`mainVideoUrl`；只有 `videoId` 时拼云视频候选直链

## 2. 价格：每个 SKU 取各自的价格

以前取的是「页面当前点选的那个规格」的价格，再被我上一版的商品价兜底铺平。
本轮加了 **页面数据钩子**：

- 新增 `src/page-hook.js`（MAIN world，`document_start`，只在 `item.htm` 注入）：
  旁路记录商品页自己调到的 mtop 响应（`pcdetail` / `getdetail`），不改页面逻辑、不重放请求
- 新增 `src/page-data.mjs`：从这些响应里解析 `skuBase` + `sku2info`，
  按 `skuId` 把**每个规格自己的价格**贴回规格行
- `background.saveToPool`：接口与页面两份 SKU 列表，取「有价格的条数更多」的那份，
  不再让无价列表覆盖带价列表
- 商品价兜底仍然保留，但只在**完全拿不到该 SKU 价格**时生效

## 3. 1:1 主图抓成了 3:4

页面上主图位展示的常常是 3:4 竖图，DOM 抓下来自然就是竖图。
现在优先用接口里的 `images`（真正的 1:1 原图列表），`verticalImages` 等键归到 3:4；
DOM 采集只作兜底。

## 4. 表头与价格/库存列对不齐

表头原来独立一套网格，和 9 列数据行（勾选/图/替换/星/规格名/价格/库存/编辑/删除）不一致。
现在表头直接复用行的网格类 `sped-sku-row`，列宽、间距、内边距完全一致。

## 5. 类目层级显示成 5 级

类目名本身带斜杠（如「零食/坚果/特产」），以前按 `/` 切就多出两级。三处一起改了：

- 插件 `content.js` 的 `validParts`
- 插件 `background.js` 的 `toLevels`
- 工作台 `editor.js` 的 `categoryPathLabel`

现在只按 `>` `›` `→` `|` `、` `,` `，` 分层，显示为
`一级 零食/坚果/特产 › 二级 糖果零食 › 三级 传统糖果`，与老软件一致。

## 6. 选三级类目后上面两列跳回顶部

类目弹窗每次重绘都重建 DOM，滚动位置归零。新增 `renderKeepCatScroll()`：
选中叶子类目时记录三列的 `scrollTop`，重绘后按列恢复，二级/一级不再跳。

## 升级与验证

1. 扩展页重新加载「AI作图插件」→ **刷新商品页**（钩子要在页面加载前注入，必须刷新）
2. 重启谢谢工作台
3. 重新点一次「加入上品库」，看提示条与 1:1/3:4/视频/SKU 价格

> 说明：1:1 主图、3:4 主图、每 SKU 价格都来自「商品页自己请求的接口响应」。
> 如果某个商品页压根不请求这些数据（例如页面还没展开图集/规格），钩子也拿不到，
> 那种情况下的兜底仍是 DOM 采集。
