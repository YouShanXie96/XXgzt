# 更新记录 v1.0.8（2026-11-11 晚二）

对应插件：**AI作图插件 0.6.14**

## 1. 视频：先封面，点一下在新窗口播放

列表里改成「封面 + 播放按钮」：`<a target=_blank>` 包住 `<video preload="metadata">`，
点封面或右侧「打开」都在新窗口播放，不再在编辑器里内联播放（内联那个在部分编码下就是黑框）。

> 采集侧的视频地址如果只有 `videoId`，插件会拼一个 `cloud.video.taobao.com/...` 候选。
> 若那条打不开，说明该页没给直链——把「打开」后的报错发我，我按真实响应改。

## 2. 1:1 与 3:4 按真实像素分类

不再靠 DOM 位置猜。采集时把候选图挂到 `Image()` 上量 `naturalWidth/naturalHeight`（走浏览器缓存，不额外下载）：

- 宽高比 ≥ 0.9 → 1:1 主图
- 宽高比 < 0.85 → 3:4 主图

这样页面上主图位展示竖图时，也不会再把 3:4 塞进 1:1。接口（页面钩子）给的 `images` / `verticalImages`
仍作为第一优先来源。

## 3. 类目：按面包屑链接取层级

之前两处问题：按 `/` 切层级（「零食/坚果/特产」被拆成 3 级）＋有的页面根本取不到。
现在：

- 只按 `>` `›` `→` `|` `、` `,` `，` 分层
- 新增**面包屑链接**提取：`#J_CrumbSlideCon` / `[class*="crumb"]` / header 里的 `<a>` 逐个取文本，
  自动排除「首页 / 天猫 / 我的淘宝 / 卖家中心」等导航词
- 参数表里的「类目路径」兜底保留

## 4. 点一次上架弹出两个「手动修改」

`registerManualFixes()` 没有并发保护，连点或队列回调重复触发会叠出两个窗口。
加了 in-flight 锁：一次只登记/打开一个，结束后才允许下一次。

## 5. 关于「点上架一点数据都没有」

这是当前实现范围问题，不是采集问题：

- 我们的 `selectionpool/driver.js` 是 **v1**：打开正确类目的发布页 → 填标题 → 把窗口亮出来交给人工，
  然后按老软件行为抛 `NEEDS_MANUAL_VERIFICATION` 停队列。
- 老软件那份日志里的 `fill-images / fill-sku / fill-detail / fill-food / fill-magix-required …`
  对应 `form-capture-publish*.js`（6 个文件约 700KB）的完整发布器，**这部分还没移植**。
- 另外上架前需要：勾选商品 + 选目标店铺 + 该店铺在客户端处于「已登录」，否则只会有错误提示、没有队列日志。

要真正做到老软件那样逐行日志 + 自动填充，需要把发布器按模块移植进 `driver.publish`
（建议顺序：标题/属性 → SKU → 图片上传 → 提交入仓 → 回执核对）。这是下一阶段的主任务。
