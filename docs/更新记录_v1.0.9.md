# 更新记录 v1.0.9（2026-11-11 晚三）

对应插件：**AI作图插件 0.6.15**

## 1. 视频封面黑、点了没反应

两个原因：

- 那条 URL 是插件**用 videoId 拼的候选**，本身不是直链 → 现在**不再拼**，只保留页面/接口真实给的地址；
  页面没给就是没采到，不再伪造一条。
- 工作台 `main.js` 里 `setWindowOpenHandler(()=>({action:'deny'}))`，`<a target=_blank>` 一律被拦 →
  新增 IPC `app.openExternal`（只允许 http/https），封面的按钮和「打开」都改走它，点一下用系统浏览器播放。

## 2. 类目采集错（把店铺名当类目）

- 插件面包屑改成**只认带类目参数的链接**（`cat=` / `categoryId` / `catId=`），并过滤
  「旗舰店 / 专营店 / 好评 / 评分 / 进店 / 客服」这类店铺文案
- 工作台加护栏：类目路径里出现店铺/评分字样，直接判为无效，只显示 `ID xxxx`，不再展示错路径

## 3. 品牌不跟着商品走

入库时过滤掉参数里的「品牌 / 品牌名称 / brand / 商标」。品牌一律用**目标店铺在该类目的授权品牌**
（露玉雅的商品上到腾味莱旗舰店，就用腾味莱）。

## 4. 3:4 显示 10 张

`tallSection` 里草稿与采集详情拼接后没有去重，也没限 5 张。现在按 URL 去重并截到 5 张。

## 5. 上架日志开始有内容

- `driver.publish` 增加 `input.log` 通道，内部每一步（打开发布页 / 探针结果 / 填标题回读 / 等人工）
  都写进上架队列日志，界面不再「一点数据都没有」。
- `service.autoShelf` 把每行日志连同 `itemId / storeId / stage` 一起落 `autoshelf-log`。

> 这只是发布器的第一步。老软件日志里的 `fill-attrs / fill-sku / fill-food / fill-detail / fill-images`
> 分别对应发布页的组件级填充，需要逐个移植。本轮先把「日志 + 打开 + 填标题」打通，后续按
> 你的日志逐段对照补齐（顺序：属性 → SKU（各自价格）→ 图片 → 详情 → 提交入仓）。
